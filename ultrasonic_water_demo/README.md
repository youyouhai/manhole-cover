# ESP32-S3 + US-100 水面接近监测 Demo

本工程直接测量“超声波探头到水面”的剩余距离。距离越小，表示水面越接近井盖和电子设备，被淹风险越高。不需要空桶校准，也不使用BOOT按钮。

## 接线

拔掉US-100的模式选择跳帽，使用TRIG/ECHO模式。

| US-100 | ESP32-S3 |
|---|---|
| VCC | 3V3 |
| Trig/Tx | GPIO16 |
| Echo/Rx | GPIO17 |
| 任一GND | GND |
| 另一个GND | 可不接，或接GND |

建议使用3.3V供电。若改用5V供电，Echo必须经过分压后再接ESP32。

## 30cm水桶演示分级

| 探头距水面 | 风险 | 含义 |
|---:|---:|---|
| 大于20cm | 0 | 安全，水位较低 |
| 10～20cm | 1 | 水位上升，需要关注 |
| 5～10cm | 2 | 水位较高，发出警告 |
| 2～5cm | 3 | 严重，仪器有被淹风险 |
| 连续无有效回波 | 3 | 可能进入2cm盲区、探头被淹或传感器故障 |

程序每秒输出一次，采用5次有效采样的中值，降低水面晃动造成的跳变：

```text
风险0 | 距水面 27.6cm | 安全：水位较低
风险1 | 距水面 16.2cm | 关注：水位上升
风险2 | 距水面 7.8cm  | 警告：水位较高
风险3 | 距水面 3.4cm  | 严重：仪器有被淹风险
```

## 安装注意

- 探头水平安装并垂直朝向水面，尽量位于桶中央，避免桶壁反射。
- US-100约有2cm测量盲区，因此危险阈值设在5cm，必须在进入盲区前报警。
- 连续3轮无回波按照风险3处理，但同时也可能是接线松动或传感器故障。
- 裸板不防水，只适合室内Demo。正式井下应用应更换防水探头并做好防凝露、防腐蚀结构。

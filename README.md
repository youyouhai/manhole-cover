# 智能井盖监测系统

本仓库保存智能井盖监测系统的传感器主板、相机板、网页端、云端函数及交付文档。

- `src/`：ESP32-S3 传感器主板固件
- `camera/`：ESP32-S3-CAM 拍照与上传固件
- `web/`：网页端源码
- `cloudbase/`：云端函数
- `output/`：硬件设计说明、网页界面展示、应用方案及答辩 PPT

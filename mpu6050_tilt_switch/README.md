# ESP32-S3 井盖倾角、声光告警与水位接近监测

本阶段包含MPU6050倾角检测、红色现场警示灯、有源蜂鸣器、US-100水面接近监测和双侧3144E霍尔在位检测，不包含环境光融合。

## 硬件与接线

开发板：ESP32-S3-N16R8（16 MB Flash、8 MB OPI PSRAM）。

| MPU6050 | ESP32-S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO8 |
| SCL | GPIO9 |
| AD0 | GND或悬空通常为0x68；接3V3为0x69，程序可自动识别 |
| INT、XDA、XCL | 不接 |

两块3144E霍尔模块分别安装在井盖左右两侧。模块固定在井盖上，两个磁铁固定在井圈对应位置；井盖正确归位时，两块模块都应感应到各自的磁铁。

| 左侧3144E模块 | ESP32-S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| DO | GPIO7 |
| AO | 不接（该模块资料注明AO无效） |

| 右侧3144E模块 | ESP32-S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| DO | GPIO10 |
| AO | 不接（该模块资料注明AO无效） |

必须使用3.3V给霍尔模块供电，使DO高电平不会超过ESP32-S3允许的3.3V。3144E是单极性霍尔开关，如果磁铁靠近但感应灯不亮，应将磁铁翻面后再试，不要通过短接引脚测试。程序按资料定义：感应到磁铁时DO为低电平，无磁铁时DO为高电平。

程序分别对两路输入做100ms消抖，并要求组合状态稳定800ms才确认变化：

| 左侧磁铁 | 右侧磁铁 | 霍尔状态 | 含义 |
|---|---|---|---|
| 有 | 有 | 两侧在位 | 井盖完整归位 |
| 无 | 有 | 左侧离位 | 左侧翘起、偏移或磁铁错位 |
| 有 | 无 | 右侧离位 | 右侧翘起、偏移或磁铁错位 |
| 无 | 无 | 两侧离位 | 井盖开启、明显移位或搬离 |

双侧霍尔已与现场声光联动：只有左右两侧均离开磁体并稳定持续10秒，GPIO2倾斜警示灯才强制常亮，GPIO6无源蜂鸣器以700Hz低音持续鸣叫。任意一侧重新检测到磁体后，霍尔联动立即解除，GPIO2恢复由原倾角报警控制，GPIO6恢复由原水位报警控制。单侧离位只记录并上传状态，不触发声光。串口输入 `HALL` 并回车可立即查看两侧状态。

红色LED模块使用板载限流电阻，按模块丝印连接：

| LED module | ESP32-S3 |
|---|---|
| GND | GND |
| VCC | 3V3 |
| IN | GPIO2 |

不要按照商品图把 `IN` 与 `VCC` 短接；那种接法会让灯永久点亮，无法由程序控制。本项目使用高电平点亮：GPIO2为HIGH时亮，LOW时灭。

有源蜂鸣器模块按丝印连接：

| 蜂鸣器模块 | ESP32-S3 |
|---|---|
| GND | GND |
| VCC | 3V3 |
| I/O | GPIO4 |

当前按用户提供的高电平触发型号配置：GPIO4为HIGH时响，LOW时停止。模块自带S8050驱动，GPIO只控制I/O。不要把I/O接到VCC。

US-100必须拔掉模式跳帽，使用TRIG/ECHO模式：

| US-100 | ESP32-S3 |
|---|---|
| VCC | 3V3 |
| Trig/Tx | GPIO16 |
| Echo/Rx | GPIO17 |
| 任一GND | GND |
| 第二个GND | 可不接，或接GND |

程序直接使用探头到水面的距离，不计算桶内水深，也不需要校准。US-100不参与原倾角风险、告警锁存或BOOT，只控制下面这组独立的水位灯和无源蜂鸣器。

第二个LED模块：

| 第二个LED模块 | ESP32-S3 |
|---|---|
| GND | GND |
| VCC | 3V3 |
| IN | GPIO5 |

HY-508无源蜂鸣器模块：

| HY-508 | ESP32-S3 |
|---|---|
| 外侧 `-` | GND |
| 中间脚 | 不接（NC） |
| 外侧 `+`/`S` | GPIO6硬件PWM，建议串联100～220Ω电阻 |

HW-508/KY-006是两端无源蜂鸣器，许多版本的三针排针只有两个外侧脚实际使用，中间脚为NC。`+`/`S`是PWM信号端，不是持续3.3V电源端；把两个外侧脚直接接3.3V和GND会给线圈施加持续直流，可能造成发热和损坏。串联电阻用于限制GPIO峰值电流；需要更大音量时应增加三极管驱动，而不是直接提高GPIO负载。

| 探头到水面的距离 | 第二个LED | 无源蜂鸣器 |
|---:|---|---:|
| 小于10cm | 常亮 | 2400Hz高音 |
| 10cm至小于20cm | 每0.5秒亮灭切换 | 1500Hz中音 |
| 20～30cm | 熄灭 | 700Hz低音 |
| 大于30cm或连续无回波 | 熄灭 | 停止 |

这组水位声光与原GPIO2倾角红灯、GPIO4有源蜂鸣器完全分开。水位变化不会点亮原红灯、不会改变原有蜂鸣节奏，也不会锁存倾角告警。

串口输入 `WTEST` 并回车，可脱离超声波强制执行3秒水位声光自检：700Hz低音1秒、1500Hz中音和闪灯1秒、2400Hz高音和常亮1秒。GPIO6使用ESP32-S3硬件LEDC PWM输出。

### 红灯防误报逻辑

- 0～10°为风险0级轻微倾斜，不触发声光动作。
- 10°以上的倾斜必须连续保持10秒，GPIO2倾角灯和GPIO4有源蜂鸣器才开始动作。
- 不足10秒就恢复到10°以下：取消计时，不产生声光动作，用于过滤车辆碾压等短时抖动。
- 10～20°：GPIO2灯闪烁；20°以上：GPIO2灯常亮。
- 红灯触发后保留锁存保护；当井盖回到原有正常倾角区间并连续稳定20秒时，程序自动解除倾斜报警。20秒内再次离开正常区间会取消并重新计时。
- 告警锁存写入ESP32非易失存储，断电重启后仍会恢复红灯告警。
- 旧零位只用于发现异常，不强迫维修后的井盖机械位置与旧零位完全一致。
- 工作人员检查并安装好井盖后，在新的正常位置长按BOOT 2秒；程序检查静止状态，把当前位置保存为新0°，成功后才熄灭红灯。
- MPU6050未连接、校准期间明显移动或新零位保存失败时，维修复位失败，红灯继续锁定。
- MPU6050持续故障属于3级设备异常，同样在持续10秒后亮灯，采用失效安全策略。
- 90°以上为5级井盖翻面。

### 蜂鸣器分级节奏

该模块是有源蜂鸣器，内部音调固定，程序通过不同鸣叫节奏表达等级：

| 锁定风险 | 鸣叫方式 |
|---:|---|
| 1级（10～20°） | 每3秒短鸣一次（响300ms） |
| 2级（20～30°） | 每3秒短鸣一次（响300ms） |
| 3～5级（30°以上） | 持续鸣叫 |

- 蜂鸣器与红灯共用10秒持续确认，不会被短时车辆冲击触发。
- 告警锁定后保留曾出现的最高风险等级用于事件记录，但鸣叫节奏跟随当前风险变化。
- 告警后角度降低时，声光按当前等级降档；回到正常区间后先维持最低级提示，连续稳定20秒后自动停止。
- BOOT维修复位功能仍然保留；需要重新建立安装零位时，工作人员仍可长按BOOT完成重设和消警。
- 锁定风险等级和告警状态都写入ESP32存储，断电重启后恢复。
- 工作人员维修归位、成功保存新0°后，红灯和蜂鸣器同时解除。

### 三模块协同流程

```text
MPU6050连续判定倾角达到10°以上并保持10秒
  → 锁存安全告警并保存等级
  → 1级闪灯，2～5级常亮
  → 1～2级长间隔鸣声，3～5级持续鸣叫
  → 风险降低后最低保持1级闪灯和长间隔鸣声
  → 工作人员维修并长按BOOT
  → 蜂鸣器临时静音，红灯继续亮，MPU6050建立新0°
  → 新0°校准并保存成功
  → 红灯熄灭、蜂鸣器停止、重新进入监测
```

维修校准时临时关闭蜂鸣器，是为了避免蜂鸣器机械振动传到MPU6050并造成“设备正在移动”的误判。校准失败时红灯不会熄灭，蜂鸣器恢复鸣叫。

无锁定告警时，系统启动后会让红灯与蜂鸣器短暂工作约180ms，作为接线自检。锁定告警恢复启动时跳过自检并直接恢复告警。

## 已实现功能

- 100 Hz 同步读取三轴加速度和三轴陀螺仪。
- 使用陀螺仪跟踪快速转动，用加速度重力方向长期校正漂移。
- 计算相对安装零位的总倾角、Roll变化、Pitch变化和角速度。
- 识别轻微、明显、中度、重度、严重倾斜和井盖翻面。
- 不同风险使用不同确认时间；升级快、恢复慢，降低临界角抖动。
- 首次校准将正常井盖姿态保存到 ESP32 NVS；以后断电重启不会自动覆盖零位。
- 上电检查静止程度并更新陀螺仪偏置；设备移动时拒绝错误校准。
- 事件包含状态持续时间、该状态最大角度和恢复原因。
- MPU6050掉线1秒后进入故障状态，每2秒重试，恢复后继续工作，不再永久死机。
- 输出加速度峰值、融合拒绝次数、温度和读取失败次数，方便现场调参和健康检查。
- 倾角达到10°以上持续10秒后触发声光告警；回到原正常区间连续20秒可自动解除，也可由工作人员通过BOOT维修复位并建立新0°后解除。
- GPIO2灯按1级闪烁、2～5级常亮；GPIO4有源蜂鸣器按1～2级长间隔鸣声、3～5级持续鸣叫。
- US-100每200ms进行一次非阻塞测距，每5个有效样本取中值；回波等待30ms，允许2～450cm标称范围。测距只控制GPIO5第二灯与GPIO6无源蜂鸣器，不会触发或阻止原倾角声光报警。

MPU6050没有磁力计，无法可靠测量绝对航向角（Yaw）；井盖倾斜、翻转和倒置检测不需要绝对Yaw。

## 默认状态阈值

| 状态 | 进入阈值 | 退出阈值 | 默认确认时间 | 风险级别 |
|---|---:|---:|---:|---:|
| NORMAL（轻微倾斜） | — | 低于8° | 2秒 | 0（0～10°） |
| SLIGHT_TILT（明显倾斜） | 10° | 8° | 1.2秒 | 1（10～20°） |
| TILT_WARNING | 20° | 18° | 1.5秒 | 2 |
| TILTED | 30° | 27° | 0.6秒 | 3 |
| FLIPPED（严重倾斜） | 45° | 42° | 0.25秒 | 4 |
| INVERTED（井盖翻面） | 90° | 85° | 0.25秒 | 5 |

阈值是原型初值。实际井盖安装后，应根据正常交通振动、井盖尺寸和允许间隙采集数据再调整。

## 首次使用

1. 把 MPU6050刚性固定，保持井盖处于正常关闭姿态。
2. 烧录并复位，保持完全静止约3秒。
3. 首次成功后会看到 `CALIBRATION_SAVED`，零位已写入非易失存储。
4. 之后重启会显示 `CALIBRATION_LOADED`，不会重新定义井盖零位。

## 串口命令

串口监视器设为115200波特率，并选择“Newline”或换行结尾。

| 命令 | 作用 |
|---|---|
| `ACK` | 执行维修复位：把当前稳定姿态设为新0°并解除锁存告警 |
| `TEST` | 红灯与蜂鸣器短暂启动，检查接线；锁定告警时拒绝执行 |
| `STATUS` | 立即输出完整状态 |
| `SCAN` | 扫描I²C总线并输出发现的设备地址 |
| `CAL` | 井盖关闭且静止时，重新标定并保存零位 |
| `CLEAR_CAL` | 清除保存的零位，随后必须执行 `CAL` |
| `HELP` | 显示命令帮助 |

不要在井盖倾斜、移动或振动时发送 `CAL`。程序会检查运动程度，但仍应保证安装状态正确。

BOOT按键按当前安全状态区分用途，不会同时执行两种操作：

- 红灯已锁定：工作人员归位后长按BOOT 2秒，程序把当前稳定位置保存为新0°，成功后同时消警。
- 红灯未锁定：长按BOOT 2秒用于重新校准零位；程序等待2秒让按键振动停止后开始采样。

此过程不要按 `RST`，也不要让 `GPIO0` 持续接地。正式产品应使用独立维修按键或NFC/蓝牙工单授权替代BOOT消警。

## 串口输出

默认每2秒只输出一行简洁信息：

```text
倾角 2.3° | 状态：轻微倾斜 | 风险：0级
```

状态变化时输出：

```text
>>> 状态变化：中度倾斜 -> 重度倾斜 | 角度 31.4° | 风险 3级 | 上一状态持续 8.2s
```

发送 `STATUS` 才会输出以下完整诊断字段：

- `state`：当前稳定状态。
- `risk`：0到5级倾角风险。
- `angle_deg`：相对正常井盖姿态的总倾角，范围0到180°。
- `roll_deg`、`pitch_deg`：相对安装姿态变化量。
- `rate_dps`：倾角变化速度。
- `accel_g`、`peak_g`：当前与最近一秒加速度峰值。
- `state_duration_ms`：当前状态持续时间。
- `repeat10m`：十分钟内轻微倾斜事件次数。
- `online`、`read_failures`：传感器健康信息。

状态确认变化时输出 `EVENT`，包含风险等级、上一个状态持续时间和最大角度，可直接作为后续无线报警数据源。

## 单功能验收

1. 静止关闭：保持 `NORMAL`，显示轻微倾斜，角度通常接近0°，不触发声光。
2. 约12°保持10秒以上：进入 `SLIGHT_TILT`，GPIO2灯闪烁、有源蜂鸣器长间隔鸣声。
3. 约22°保持两秒：进入 `TILT_WARNING`，风险2级。
4. 约35°保持10秒以上：进入 `TILTED`，灯常亮、有源蜂鸣器持续鸣叫。
5. 约50°保持10秒以上：进入 `FLIPPED`，风险4级。
6. 超过90°保持10秒以上：进入 `INVERTED`，显示井盖翻面，风险5级。
7. 回到零位保持两秒：恢复 `NORMAL`，事件应带有异常持续时间。
8. 异常姿态下断电重启：加载已保存零位后仍应识别异常，不能把当前位置当成正常。
9. 拔掉再接回 MPU6050：应先报告 `SENSOR_FAULT`，接回后自动恢复。

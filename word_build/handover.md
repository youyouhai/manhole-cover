### 1.2 MPU6050倾角检测

已完成并集成：

- MPU6050在线检测及自动识别`0x68/0x69`地址。
- 加速度计和陀螺仪融合计算倾角。
- 支持现场零位校准。
- 零位及陀螺仪偏置保存到ESP32非易失存储，断电后保留。
- 倾角分级、迟滞、状态确认及10秒持续触发。
- 倾角报警锁存，井盖短暂恢复原位后不会自动清除。
- BOOT键执行人工复位与重新校准。
- 传感器掉线检测与故障提示。
- 串口状态输出已经简化。

当前倾角分类：

| 角度 | 状态 | 风险级别 |
|---:|---|---:|
| 0°～<10° | 轻微倾斜 | 0级 |
| 10°～<20° | 明显倾斜 | 1级 |
| 20°～<30° | 中度倾斜 | 2级 |
| 30°～<45° | 重度倾斜 | 3级 |
| 45°～<90° | 严重倾斜 | 4级 |
| ≥90° | 井盖翻面 | 5级 |

分级变化不会立即触发声光报警，需要危险状态持续10秒。

### 1.3 倾角声光报警

倾角模块已经与第一只红灯和有源蜂鸣器联动：

- 0级：灯灭，蜂鸣器停止。
- 1级：红灯闪烁，有源蜂鸣器长间隔鸣叫。
- 2级：红灯常亮，有源蜂鸣器长间隔鸣叫。
- 3～5级：红灯常亮，有源蜂鸣器持续鸣叫。

报警触发后会锁存：

- 井盖恢复到低角度时，不会直接消警。
- 声光会降为较低强度提示，但继续提醒存在历史风险。
- 需要工作人员使用BOOT键人工确认。
- 人工确认时，程序等待井盖稳定后，将当前位置重新设为0°。
- 只有校准及保存成功后才清除锁存报警。

### 1.4 US-100超声波测距

超声波功能已经并入同一个ESP32固件，没有替换倾角功能。

已实现：

- 使用电平触发模式测距。
- 读取传感器到水面的距离，而不是直接输出水深。
- 中值滤波及连续无效数据处理。
- 测距失效时关闭水位声光输出。
- 已解决最初只能测到约22.5cm的问题，之后用户确认测距正常。
- 支持用手或平整物体代替水面进行演示测试。
- 每10秒根据距离变化计算水面上升或下降速度，单位为`cm/min`。
- 设置了0.3cm变化死区，减少测量抖动造成的虚假流速。

水位声光规则：

| 测得距离 | 第二只LED | 无源蜂鸣器 |
|---:|---|---|
| <10cm | 常亮 | 2400Hz高音 |
| 10～<20cm | 闪烁 | 1500Hz中音 |
| 20～30cm | 熄灭 | 700Hz低音 |
| >30cm或测距无效 | 熄灭 | 静音 |

水位声光报警与倾角报警相互独立。

### 1.5 双霍尔传感器

两个3144E霍尔传感器的软件读取已经集成到主程序：

- 分别用于井盖左右两侧。
- 使用数字输出DO。
- 加入输入防抖。
- 加入双侧组合状态稳定确认。
- 串口能够输出左右霍尔状态。

当前定义的组合状态：

| 左侧 | 右侧 | 判断 |
|---|---|---|
| 有磁铁 | 有磁铁 | 井盖基本在位 |
| 无磁铁 | 有磁铁 | 左侧抬起或横向偏移 |
| 有磁铁 | 无磁铁 | 右侧抬起或横向偏移 |
| 无磁铁 | 无磁铁 | 井盖打开、搬离或严重脱位 |

目前霍尔状态只进行检测和串口显示，尚未正式参与声光报警或多传感器融合。

### 1.6 串口操作命令

当前主程序支持的命令包括：

- `STATUS`：立即显示状态。
- `TEST`：倾角声光测试。
- `WTEST`：水位声光测试。
- `HALL`：查看霍尔状态。
- `SCAN`：扫描I²C设备。
- `CAL`：重新校准零位。
- `ACK`：确认并解除允许解除的倾角报警。
- `CLEAR_CAL`：清除已保存的倾角校准。
- `HELP`：显示帮助。

## 3. 已确定的技术方案

### 3.1 本地监测方案

当前本地监测拆为三个独立部分：

1. MPU6050负责姿态与倾角。
2. US-100负责传感器到水面的距离及水面变化速度。
3. 左右两个霍尔传感器负责判断井盖在位、单侧偏移或双侧脱离。

倾角和水位各自使用独立的LED、蜂鸣器和判断逻辑，不互相覆盖。

### 3.2 霍尔安装方案

已经确定：

- 两个霍尔模块安装在井盖两侧。
- 对应磁铁安装在井圈固定位置。
- 井盖正常闭合时，两侧均应感应到磁铁。
- 单侧失磁用于识别抬边或偏移。
- 双侧失磁用于识别开启、搬离或严重错位。

### 3.3 Cat.1与GPS方案

最终设备不依赖固定Wi-Fi。

开发顺序确定为：

1. 前期可以用Wi-Fi或手机热点调试云端接口。
2. GPS位置仍由Cat.1/GNSS模块产生。
3. 云端接口验证成功后，再把上传链路切换到Cat.1流量。
4. 视频和AI识别暂不纳入当前阶段。

Cat.1模块采用DTU固件，通过UART接收ESP32产生的传感器数据，再通过移动网络转发到服务器。

### 3.4 云端网页方案

计划沿用之前成功使用过的架构：

- Cloudflare Workers：接收设备上报。
- Durable Objects：保存设备最新状态并管理实时连接。
- WebSocket：实时推送状态变化。
- Cloudflare Pages：托管地图和监控网页。
- Pages Functions：连接网页和云端状态服务。

规划的数据链为：

```text
传感器 → ESP32 → Wi-Fi调试或Cat.1 → HTTPS/TCP接口
                                      ↓
                              Cloudflare Worker
                                      ↓
                              Durable Object
                                      ↓ WebSocket
                              Cloudflare Pages
                                      ↓
                                  手机/电脑
```

该云端方案目前属于已确定架构，尚未在当前工程中实施。

网页地图需求已确定为两类图标：

倾角图标使用水滴形：

- 绿色：轻微倾斜。

## 6. 下一步建议

建议严格按以下顺序推进，避免同时修改多个已经工作的模块。

1. 在银尔达DTU平台进入“测试”分组，点击“分配设备”，将当前未分组的M100MG-C1设备加入该分组。
2. 等待设备再次请求参数，确认设备分组变为“测试”，设备参数版本更新为2。
3. 重新上电，观察RDY灯是否亮起，并检查EasyIoT平台是否由离线转为在线。
4. 到窗边或室外开阔位置测试GPS，确认GPS灯和经纬度数据。
5. 在不修改现有传感器算法的前提下，为ESP32加入独立的Cat.1 UART测试模块，仅发送固定测试字符串。
6. 固定字符串透传成功后，再发送倾角、水位、流速和双霍尔状态。
7. 确定统一JSON字段和设备ID规则，再搭建Wi-Fi调试版Cloudflare接口。
